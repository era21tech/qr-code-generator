# qr-code-generator
A simple and clean QR Code Generator web app. Enter any text or URL and instantly generate a scannable QR code. Built using HTML, CSS, and JavaScript with a smooth UI and quick QR rendering

## 🚀 Features

* Generate QR codes instantly
* Clean and responsive UI
* Error animation for empty input
* Auto display animation for generated QR

---

## 🛠️ Technologies Used

* **HTML** – Interface structure
* **CSS** – Styling & animations
* **JavaScript** – QR generation functionality

---

## 📷 How It Works

1. Type your text or URL
2. Click **Generate QR Code**
3. Your QR code appears instantly

---

## 📦 Files Overview

* **index.html** – UI layout and JavaScript logic 
* **style.css** – Styling, layout, animations 

---

## 🔧 QR Code API Used

The app uses:

```
https://api.qrserver.com/v1/create-qr-code/
```
